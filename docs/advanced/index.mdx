# Advanced Features

In-depth and extra semantic-model features. This section lives **under Semantic Model**: the top-level docs cover core basics (tables, fields, expressions, relationships); Advanced covers more in-depth and optional topics.

## Features

- **[Extended Blending Groups](/developer-guide/advanced/extended-blending-groups)** - Blend dimensions across tables
- **[Exclusions](/developer-guide/advanced/exclusions)** - Filter-based measure exclusions
- **[Inclusions](/developer-guide/advanced/inclusions)** - Multi-level calculations
- **[Partitions](/developer-guide/advanced/partitions)** - Data availability constraints
- **[Cost Optimization](/developer-guide/advanced/cost-optimization)** - Query routing and performance
- **[Decorators](/developer-guide/advanced/decorators/temporal)** - Transformations (temporal, window, contribution)
- **[Multi-Datasource](/developer-guide/advanced/multi-datasource)** - Cross-datasource queries

## When to Use

Use advanced features when you need:
- **Cross-table dimension blending** - Extended blending groups
- **Point-in-time analysis** - [Snapshot measures](/developer-guide/semantic-model/fields/measures/snapshot)
- **Complex filtering** - Exclusions
- **Multi-level calculations** - Inclusions
- **Data constraints** - Partitions
- **Performance tuning** - Cost optimization
- **Time-based analysis** - Temporal decorators
- **Cross-database queries** - Multi-datasource
