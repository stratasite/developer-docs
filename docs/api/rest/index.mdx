# REST API

Programmatic access to Strata semantic metadata and query execution.

## Overview

The Strata REST API v1 exposes the semantic layer for external applications, automation, and integrations. Use it to:

- Discover fields and tables on a deployed branch
- Preview and run queries against the semantic layer

:::tip API Reference
For the full endpoint schema and payload reference, open the interactive OpenAPI docs in a new tab: [API Reference](pathname:///api/rest/openapi).
:::

All endpoints return JSON unless noted otherwise. Base path:

```
{server}/api/v1
```

## Prerequisites

- A running Strata server with at least one deployed project
- An API key from **Settings → API Keys** in the Strata web app
- Project membership

See [Authentication](/developer-guide/api/rest/authentication) and the [Quickstart](/developer-guide/api/rest/quickstart) to make your first request.

## Endpoints

### Semantic metadata

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/projects/{project_id}/fields` | [List/search fields](/developer-guide/api/rest/fields#list-fields) |
| `GET` | `/projects/{project_id}/fields/{id}` | [Show field](/developer-guide/api/rest/fields#show-field) |
| `GET` | `/projects/{project_id}/tables` | [List/search tables](/developer-guide/api/rest/tables#list-tables) |
| `GET` | `/projects/{project_id}/tables/{id}` | [Show table](/developer-guide/api/rest/tables#show-table) |

### Queries and results

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/projects/{project_id}/queries` | [List API queries](/developer-guide/api/rest/queries#list-queries) |
| `POST` | `/projects/{project_id}/queries` | [Create or re-run query](/developer-guide/api/rest/queries#create-or-re-run-query) |
| `GET` | `/queries/{id}` | [Show query](/developer-guide/api/rest/queries#show-query) |
| `DELETE` | `/queries/{id}` | [Delete query](/developer-guide/api/rest/queries#delete-query) |
| `POST` | `/projects/{project_id}/sql` | [Preview SQL](/developer-guide/api/rest/sql#preview-sql) |
| `GET` | `/queries/{query_id}/sql` | [SQL for saved query](/developer-guide/api/rest/sql#sql-for-saved-query) |
| `GET` | `/queries/{query_id}/result` | [Poll result](/developer-guide/api/rest/results#poll-result-via-query) |
| `GET` | `/projects/{project_id}/results/{id}` | [Show result](/developer-guide/api/rest/results#show-result) |
| `DELETE` | `/projects/{project_id}/results/{id}` | [Cancel result](/developer-guide/api/rest/results#cancel-result) |
