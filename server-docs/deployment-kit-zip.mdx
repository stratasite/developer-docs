# Deployment Kit ZIP

Strata release workflows publish a deployment kit ZIP artifact for enterprise handoff.

## What the kit contains

- `single-server/install.sh`
- `single-server/.env.example`
- `docs/DEPLOYMENT_GUIDE.md`
- `docs/OPERATIONS.md`
- `docs/SECURITY.md`
- SHA256 checksum file

## How to use

1. Download the ZIP from the release artifact.
2. Verify checksum.
3. Choose a deployment path (single-server or AWS ECS manual).
4. Follow included guide files.

## Checksum verification

```bash
shasum -a 256 -c strata-enterprise-deployment-v<version>.zip.sha256
```

## Versioning guidance

Use a deployment kit that matches your intended server image tag.

- Example image: `registry.gitlab.com/stratado/server:1.2.3`
- Matching kit: `strata-enterprise-deployment-v1.2.3.zip`
