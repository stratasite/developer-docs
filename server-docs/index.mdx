# Server Installation

Strata Server is the self-hosted web application for semantic analytics and BI workflows. It is distributed as a private container image and supports multiple deployment approaches.

## Deployment Flow

1. Start with [Choose Your Deployment Path](/server/deployment-paths)
2. Follow the selected deployment guide
3. Validate runtime health and background processing

## Runtime Architecture

Strata Server supports these runtime roles from the same container image:

- **web**: HTTP application service
- **worker**: background processor service
- **all** (or unset `STRATA_PROCESS_TYPE`): runs web and worker in one container

Recommended production topology is split services (`web` + `worker`) for independent scaling and fault isolation. Single-container `all` mode is supported for smaller environments and simplified deployments.

Naming convention in this documentation:

- **Role names:** `web`, `worker`, `all`
- **Service names:** use `web` and `worker`
